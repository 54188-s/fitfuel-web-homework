# 0.13.0 · 相遇与表情

本轮完成任务书4.3基础表情和5.3初次相遇的一段体验：认识分身、直接去记录、了解休息与生活。原人类、房间、347动作／113食品／837帧以及用户确认的网页首页保留。训练和饮食仍从原页面录入。

## 已实现

- 首次相遇是三段行内对话，随时跳过、稍后重看，已经保存的步骤可继续。没有遮罩锁住页面，也不要求先填身体数据。旧版已有本机使用痕迹时不强迫重走；可以主动打开“相遇说明”。
- “先选个样子”打开原分身编辑器。其他两段直接通向原训练、饮食页，介绍生活间已有的休息、探索和收藏。
- 原创三种表情为开心、专注、放松，保持原人类身份、分层发型和肤色。换肤缓存仅在外观变化时生成，帧循环不读存储。原中性头部保留，表情素材缺失时可退回原图。
- 训练／准备时专注，休息／暂停时放松，用餐时开心。真实训练状态优先。“和分身打个招呼”有短回应；站立且非行走时有抬手动作。静态、隐藏与真实训练时不触发这项临时互动。
- 原API成功保存训练／饮食时显示短回应，可以关闭主动的记录回应。手动招呼仍可用。重开近期训练不会重播新文字提示。两条不同饮食即使修订号都为1，也分别识别；修改或取消反馈不留过时的文字。
- fitfuel_meeting_v1只存引导进度和回应偏好，不生成健康事实、XP或灵感。未知版本与损坏数据保留，写失败不假装成功；可本次收起并继续使用健身入口。

## 边界与回滚

这不是任务书全部完成：仍缺少精确逐动作陪练、更多场景事件、完整月度复盘、热身／超级组、常用餐、GPS与账号云同步。独立微信小程序仍184动作／110食品，本轮未同步这些新生活交互。网页与App存档各在本机，不是跨端云同步。手机安装、系统照片／分享、后台、微信真机及性能未验收。

当前一段固定叙事和少量视觉状态使用小型独立模块，未改原健康架构。十倍场景最先需要将叙事及表情映射数据化、拆分资产按需加载，不能靠继续扩大内嵌载荷解决。回滚到b104bf63aa819530e3d3fb00798979b6e8b9e14f或保留的0.12.0工程／APK；新视觉键旧版忽略，原健康键不迁移。正式同步逐文件备份后执行，不整目录覆盖。
