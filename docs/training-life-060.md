# 0.6.0 · 真实逐组训练与数字分身

本轮对应任务书4.1、4.3、4.4及阶段1／2。沿用同一网页训练页和fitfuel_training草稿，补齐每组独立次数／重量与确认、开始／暂停／恢复／结束、60／90／120秒或关闭自动休息。人物只投影确认保存后的真实训练／暂停／休息状态，入口可返回同一训练。完成历史仍是fitfuel_history；经验、回忆读取它，游戏没有自己的动作库或健康表单。

补录不要求开计时；整动作补录仍保留，单次写入确认全部组。保存只包含勾选的实际组，逐组次数和负重保持，未完成组不当成完成。计时统计包含训练与组间休息，扣除手动暂停；补录时长标为未计时。沿用现有力量估算方法，按完成组汇总，方法和输入体重随记录保存；不是实际测量，未改已有历史的热量，也未宣称已完成任务书中更完善的个性化能耗模型。

休息截止只改变提示，不勾选下一组。暂停保留剩余休息，导航离开／重开可恢复，停止计时保留已勾选的草稿，不自动存训练历史。跨午夜保留进行中组；实际计时训练按结束当地日期归档，开始／结束时间另存。设备时间倒退时阻止变更并提示校正。减少动态、静态与隐藏设置继续有效；计时画面每秒只计算显示，不轮询健康记录或写入存档，离页清理。

结束采用原草稿中的待保存意图：先确认意图，再写单一稳定编号的历史，最后确认结束。任一步写失败会保留可重试状态；已落盘历史不重复生成、不覆盖恢复期间的用户更正。若历史已写入而收尾未确认，界面明确说明历史已保存、需要重试。这个短暂状态下先阻止删除对应历史；完成重试后可正常删除，删除的完成记录不会因再次点击被恢复。其他旧记录不变。没有宣称多设备事务或防作弊。

参考：重读项目已有RESEARCH-RECORDING.md的Hevy逐组与休息流程、RESEARCH-COMPANION-IDLE.md的Walkr／Walking RPG与温和陪伴分析；本轮核对[openGym官方功能](https://opengym.ch/)及[官方仓库](https://github.com/DuarteSantos8/openGym)。openGym为AGPL-3.0，其逐组确认与计时流程作为交互参考；本轮没有导入其React／服务端代码、角色或媒体，没有新增运行依赖。已有报告明确区分公开资料、静态分析与实机结果，本轮未冒称重新安装过这些竞品。

实际验证：新增24项训练与人物投影测试，原37项融合／导入／回忆测试保持，共61项通过。新增37项离线浏览器检查，真实填写8次／30kg与6次／35kg，只确认两组；暂停、切页重开、休息截止不勾选、关闭休息、写失败回退、完成历史、20经验及回忆共用事实均已实测。原43项表单／收藏／房间和17项回忆浏览器回归通过；2587项资源、语法、20页两宽度与原素材／首页摘要检查通过。桌面与390、360宽度检查不是手机真机验收。

本轮只补真实训练联动。任务书仍缺自主生活事件、探索地点与发现、用户照片相册、完整日周月复盘、训练历史任意编辑、超级组／热身组／长期进步对照、顺序餐次与常用餐、GPS与云同步等。继续按优先级推进，不用空按钮或虚假记录代替。旧0.4原生在途草稿仍只归档，未自动转换为新逐组会话。

设计复核：扩展原健康草稿，不引入游戏专用训练事实；逐组控制器共供训练页和生活间使用。计划结构在进行中锁定，防止改模板丢组；保留原动作图、食品数据、收藏、首页与课程框架。固定休息选项是产品预设，未知版本／损坏数据保留，恢复只基于已确认落盘记录。十倍规模下整文档读写、历史索引、事件增长和跨标签页并发是优先风险；本轮未更换数据库／框架，也未宣称已解决多窗口同时编辑。
