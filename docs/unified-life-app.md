# FitFuel 0.5.0：网页、生活间与 App

这版把原游戏生活间接入已有网页健身功能，并继续补齐任务书中的成长回忆。游戏没有另一份动作库、食品库、饮食计算或健康记录表单：它直接取得当前页面的FitStore、FitData、FitCalc，前往网页现有的训练、饮食和身体页面。Android App同样打包这些HTML、JavaScript、图片和视频，增加五个底部入口，默认打开生活间。

当前统一目录为347个动作、837张实际展示图、113种食品。保留粗线帧筛除结果，191组三图／108组两图／48个单图；动作详情通用视频仍删除。原110种食物保持，补入原生App已核对的USDA生鸡胸、烤熟鸡胸、生黑米3条，并保留来源和CC0许可。未补造熟黑米饭数据。

网页原有的身体档案、指标／体重、训练计划／打卡／历史、动作搜索／收藏／图示轮播、食物搜索／自定义食物／份量、今日饮食和营养分析继续使用原实现。你选定的桌面首页主视觉、原青绿色、数据环和布局保持，左侧增加“我的生活间”。App的“更多”可进入全部现有页面。

成长规则保持试用约定：开启后，当天首条新训练20经验、首条新饮食10经验；每15分钟探索1灵感，每次最多8小时，手动领取；累计领取1／4／8／16点解锁四件房间收藏，摆放不花灵感。陪练动画、浏览图库、体重变化和补录历史不发经验。休息不扣进度。

健康事实仍保存在原fitfuel_meals／fitfuel_history等键。原保存边界为成功写入的记录附加创建／更新时间与版本；生活间只维护引用和追加观察事件，再由既有游戏引擎按每日规则结算。记录、观察或奖励写入失败都能重试；原记录不靠游戏动画推断。旧记录没有新建时间时按历史处理，不补发奖励。观察索引损坏／版本未知时暂停结算并保留原值。

旧0.2网页App继续使用https://localhost和原网页存储键。新版沿用com.fitfuel.foundation、versionCode6，开发签名与原0.4原生包匹配；满足覆盖升级的必要条件，手机实际安装仍待用户验证，升级前不要卸载或清数据。0.4原生偏好数据只读，通过生活间的“接回旧App的记录”显示数量后由用户导入。现有网页记录优先保留；饮食使用原营养快照，历史逐组次数／负重保留，原版未存的热量标为“热量未记录”。原始档案另存，失败可重试，有新编辑时停止覆盖。

App本轮使用网页已有的训练计划与打卡界面。旧原生版正在进行的逐组草稿原样保存在原始档案，不自动转为已完成训练；本轮没有迁入原生版60／90／120秒组间计时界面。生活间的陪练／60秒休息只改变人物表现。这个限制需要在覆盖升级前了解，旧原生工程与安装包仍保留。

旧原生档案缺少的性别、体脂等字段不编造成已记录数据；导入后请在身体档案确认。旧手动热量目标可沿用，编辑并保存身体档案后按网页原公式重算。原生体重超出网页支持范围的条目保留于原始档案，不默默截断。

本次同步的是代码、目录、功能与素材。同一个网页／App内的健身页和游戏共用本机记录；电脑浏览器和手机、不同浏览器之间仍各有本机存储，没有云同步。此前独立小程序预览的记录没有自动混入网页。没有接入真实步数、服务器账号或广告。

生活间的人类角色、房间和四件收藏使用此前原创素材。三个PNG在生活间专用源码包中内嵌，解决双击本地HTML时画布换色的跨文件限制；原PNG、来源、可编辑游戏模块和重建脚本也随工程保留。没有新增逐帧存储轮询，离页清理动画。减少动态效果时，首次默认静态；用户已有设置优先。

工程与验证：网页入口为fitfuel-course/index.html，生活间为html/life.html，手机／App入口为app.html。engineering/life-src包含15份可编辑游戏源文件，engineering/rebuild-life.py只用Python标准库重建生活间源码包；健康计算与存储源只在fitfuel-course/js中。App源码包中website是同一份完整网页工程，app-shell是Android封装；同步脚本生成App资源，避免维护第二套业务代码。

已有结果：27项融合与导入测试、43项实际浏览器流程、837图实际解码与2338项轮播检查通过；原小程序166项回归保持通过，App自有4项主机测试通过。浏览器流程实际使用原饮食与训练表单，观察30经验和四件摆放，不用演示记录伪装联动。最终包与源码核验另见交付校验记录。没有完成Android系统模拟器／手机真机安装、键盘、手势和性能验收。

设计复核采用最小适配：健康模块保持既有边界，游戏只读取确认事实；App使用已有Capacitor，未新增另一套界面框架。十倍数据规模下，整文档健康记录、追加观察索引与游戏奖励日志的读取，以及全库搜索和贴图内存最先需要检查。先记录风险，不在本轮另做数据库／云端重构。独立提交和回滚点随交付记录提供，开始前基点6966ef9597f5f96bdcfbad70ed1531ceaff27f69。
