# 0.7.1 · 动作分类只显示相应主要部位

修复用户反馈：选肩部仍先见到胸部，选腿部先出现背部动作。修复前以真实分类点击和Node断言复现：胸部分类51项混入肩／背／手臂／核心／有氧等；原因是js/search.js的inGroup把主要category和所有辅助肌群tags合并匹配。点击参数与动作配图生成没有错；错误在筛选成员，因此重新排序不能解决。

现在浏览分类按主要category匹配；腿汇总腿／股四头／腘绳肌／臀／小腿，手臂汇总手臂／二头／三头／前臂。旧数据中主要分类只有腿或手臂时，细分标签只在同一家族内进一步匹配，不让其他部位借辅助标签混入。辅助肌群仍写在动作说明中，“全部”中的关键词搜索仍可检索它们。共347动作、837帧及所有营养数据和图片原件不变，不挪用其他动作图片填分类。

原动作库、训练动作选择器和身体导航计数共用同一个筛选函数；修复一处后同步生效。分类按钮补aria-pressed，屏幕阅读器能读出当前选择。保留收藏、最近使用、搜索、24条分页、白线图轮播、放大和原版排版。

核对的主要分类数量：胸33、背47、肩31、腿105、手臂41、核心43；加复合9、有氧23、活动度15，347动作各归属一次。细分腿／手臂分类是相应父部位内部的筛选，不改变主要归属。
