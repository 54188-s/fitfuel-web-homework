# 0.8.0 · 生活间成长相册（2026-10-23）

接任务书5.6，生活间顶部加入“成长相册”。可以给当前人类分身和房间留影，或自己选择JPEG／PNG／WebP照片，写日常或阶段纪念；也可只写文字。只有确认保存才入相册，草稿可放弃。照片会缩小到最长1280像素，原文件不改动。相册支持查看、编辑、分类、12条分页、删除照片／纪念和JSON备份恢复。

原首次训练／饮食回忆新增“为这次留念”。只存原记录编号与类型，不复制健康事实；查看时按编号读取完整历史，跨天不会把旧饮食误认为已删。原记录删除时会明确说明，个人纪念仍由用户自己保留或删除。手写阶段纪念不是系统验证的目标达成；自动力量纪录和阶段目标里程碑仍待补齐。相册保存不发经验、不改探索奖励，也不创建训练或饮食记录。

照片和文字用本机IndexedDB保存，元数据与照片Blob分两个存储区，同一事务提交。中断、空间不足、删除和批量恢复均以事务完成为确认边界；失败保留原内容。列表只读元数据、按当前页取照片，关闭或切换页面释放预览URL。每次编辑检查修订，阻止旧页面覆盖新内容；导入先预览，重复跳过，冲突保留为独立纪念；预览后本机有变动必须重新预览。未来版本或损坏内容保留，其他健康功能继续可用。

本机相册最多200段；上传源图最大8MB，处理后单图最大600KiB，备份文件上限170MiB。导出和导入会处理整份照片，相册较大时的移动端内存和系统文件选择仍待真机检查。浏览器提供JSON下载，Android沿现有Filesystem缓存与Share插件打开系统保存／分享窗口。相册不上传、不云同步；网页与App各自存本机，相册需单独备份，不随本地演示账号隔离。原健康数据备份没有自动包含相册，换设备前使用相册自己的导出／恢复。

UI沿现有房间的暖木、奶白和绿色，使用当前房间画面及用户自选图片，没有下载或生成另一套角色。相册在独立对话界面内，打开时暂停房间绘制，关闭后恢复；实际训练计时继续由原模块管理。静态／隐藏设置保持，隐藏人物时仍能写纪念或选择照片。已看390／1440相册、详情、编辑和真实人类留影截图；360编辑宽度也检查过。原桌面首页14份摘要、347动作／113食品／837帧及分类修复保留。

开源与资料核对：研究[SimLife公开说明](https://github.com/silverlion2/simlife)的家具交互和离线存档（README自述MIT，本轮未导入代码／素材）；核对[idb-keyval](https://github.com/jakearchibald/idb-keyval)及其Apache-2.0许可、[idb事务生命周期说明](https://github.com/jakearchibald/idb#transaction-lifetime)与[W3C IndexedDB规范](https://www.w3.org/TR/IndexedDB/)。当前只需原生双存储区事务，直接用浏览器API，没有增加第三方运行依赖或框架，也没有在事务中等待图片处理／网络。

验证：新增19项元数据／备份／合并规则测试，原92项保持，共111项。51项真实IndexedDB离线浏览器检查覆盖留影／上传／重开、照片写失败同时回滚元数据、编辑与批量恢复中断、旧编辑与导入并发保护、重复／冲突恢复、真实照片实体删除、原记录关联／跨天／删除、未来版本保留、预览URL释放和360／390／1440宽度。另6项同源本机HTTP下的Filesystem／Share模拟检查核对接口与失败保留，不是真机分享验证。原202项动作分类、探索、训练、表单和回忆浏览器回归通过。测试只有隔离浏览器生成的房间图片和虚构纪念，不带入用户存档。

修改集中于js/life-album.js、life-album-ui.js、css/life-album.css、life.html装载、原life-memories.js的留念入口和companion模板按钮；游戏载荷从原17份模块重建。健康库、计算器、原角色／场景／动作图片和奖励逻辑不改。构建Android0.8.0/code10，Android构建成功，115项Gradle任务实际执行，4项自有主机测试通过；2291项APK全资源／CRC／签名／版本核验通过。20页1440／390宽度的2594项资源与布局检查通过。压缩包解压结果另见交付记录。仍没有手机安装、系统模拟器、微信原生同步、后台或性能验收，原生插件仅接口模拟与编译核验。

设计复核：相册与健康事实分开，但仅保留引用，避免照片写进localStorage或复制一份健康档案。照片与元数据需要双存储区同事务，单键工具反而多一道同步边界。没有替换既有架构。十倍规模先受全相册备份内存、照片解码和元数据排序影响，当前200段限制与按页取图是明确容量边界，不宣称无限扩容。原健康模块的整文档和跨标签并发风险仍在，本轮不借机重构。
