# FitFuel网页课程修改版

入口：双击根目录index.html（建议Edge/Chrome），或在站点目录运行 python -m http.server 8000 后打开 http://localhost:8000/index.html。

这是在原增强网页版上修改的独立课程版本，原完整包及小程序未覆盖。页面包含347个图文动作、110种内置食物、计算公式、搜索、收藏、计划、饮食、体重和本地账户。

目录：index.html为嵌套框架首页；html/为页面；images/、css/、js/、video/为本地资源；docs/为要求映射和验收说明。

联系信息统一修改js/contact-data.js。已按作者提供的信息填入姓名、邮箱、电话；学号已按作者提供的信息填入。正式提交前核实素材使用权限。
